在线打印PHP系统部署使用说明
一、部署前置环境要求（必看）
本系统强制要求 PHP 8.0 及以上版本（兼容PHP8.0、8.1、8.2、8.3），低版本PHP会出现程序报错、功能异常、支付回调失效等问题，部署前请务必在宝塔/主机后台确认PHP版本，完成版本切换。
配套基础环境：MySQL 5.7及以上版本、正常开启网站域名SSL证书（https协议）。
二、上传部署前置操作
所有操作需在文件上传至服务器前完成，避免部署失败、配置不生效等问题。
1. 创建数据库：登录宝塔面板/虚拟主机后台，新建MySQL数据库，记录好数据库名称、数据库账号、数据库密码（后续配置文件需用到）。
2. 导入数据库文件：将程序自带的sql.sql 数据库文件，导入至刚刚新建的MySQL数据库中，完成数据表初始化。
3. 修改核心配置文件（config.php）：用记事本/代码编辑器打开根目录 config.php 文件，逐项修改以下配置信息，确保信息准确无误：
        
  - 数据库配置：填写刚才创建的MySQL数据库账号、密码，确保与服务器数据库信息完全一致；
  - 站点域名配置：site_url 修改为自己的正式域名（格式示例：https://Baidu.com），必须填写完整带https的域名，不可填写IP、残缺域名；
  - 易支付配置：epay_pid（商户ID）、epay_key（商户密钥）、epay_gateway（支付网关地址） 全部替换为自己的易支付官方信息；
  - 后台安全配置：admin_password 修改为自定义后台登录密码，建议设置复杂密码，保障后台安全。
三、程序文件上传方法
将程序压缩包内的所有文件、文件夹，完整上传至网站根目录（请勿单独上传部分文件，请勿新建子目录存放程序），上传完成后检查文件完整性，避免缺失文件导致程序报错。
四、目录权限设置（关键步骤）
系统缓存、文件上传、订单生成功能依赖目录写入权限，需重点设置以下两个目录权限：uploads_tmp、打印。
- 宝塔面板默认设置：权限改为 755，归属用户为www；
- 若出现上传失败、文件无法生成等问题，可临时设置为 777 权限调试，部署稳定后建议改回755保障安全。
五、系统访问地址汇总
所有地址均为「你的正式域名+对应页面路径」，域名需与config.php中site_url配置一致：
- 用户下单前台页面：你的域名/index.php
- 管理员后台登录页面：你的域名/admin.php
- 支付异步回调接口（无需手动访问）：你的域名/notify.php
- 支付成功跳转返回页面：你的域名/return.php
六、支付成功后文件存储位置说明
用户支付成功、完成文件上传后，系统会自动生成专属订单文件夹，文件存储路径为：网站根目录/打印/用户姓名_手机号后4位/订单号/
该目录下自动保存两类文件：
1. 用户上传的全部打印文件；
2. 订单信息.txt（包含订单编号、用户信息、支付信息、下单时间等完整订单数据）。
七、补充注意事项
- 全程必须使用PHP8.0及以上版本，版本不匹配会直接导致程序瘫痪、支付无法回调、文件无法保存；
- 域名必须配置SSL证书，使用https协议访问，否则支付接口会校验失败；
- 修改配置文件后需保存生效，上传文件后建议刷新网站缓存，避免配置不生效。
